Training programme

What a typical session covers

01

Introduction to the product

What it is, how it works, and what to expect during installation.

02

Container inspection

Checking the container is fit for installation before work begins.

03

Container preparation

Preparing the container so the product can be fitted correctly.

04

Installing auxiliary components

Bulkheads, valves and other supporting parts fitted before the main installation.

05

Main installation

Fitting the product itself, following our step-by-step method.

06

Final inspection & checks

Confirming the installation meets specification before the container is loaded.

07

Labels & documentation

Making sure the container is correctly labelled and documented for transport.
